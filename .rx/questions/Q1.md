# Are frozen agent verifiers invariant to mechanically evidence-preserving trajectory representations?

Primary question. For each saved trajectory, construct paired renderings that preserve the ordered tool calls, tool arguments, environment observations, final answer, and executable grader outcome while changing only wrappers, delimiters, key order where semantics permit, whitespace, or an explicitly lossless schema encoding. Freeze verifier prompt, model revision, decoding, context budget, and acceptance threshold. Measure paired absolute score change, directional score change, and decision flips, stratified by label and transformation family.

Four-axis novelty delta versus agent-verifier benchmarks (Universal Verifier/CUAVerifierBench, LLM-as-a-Verifier, AgentRewardBench) and metamorphic LLM testing: framing = the verifier is the system under an invariance test, not merely evaluated on a heterogeneous trajectory corpus; mechanism = paired transformations applied to one immutable semantic event graph with preservation checks; insight = identify whether verifier errors are attributable to presentation rather than outcome evidence; domain = long-horizon tool-agent outcome verification with executable graders. The mechanism/insight delta, not domain transfer, is the intended contribution.

Prediction/falsifier: H1 predicts non-negligible paired instability and threshold flips. A preregistered equivalence analysis whose intervals lie inside a practically negligible margin across the mechanically guaranteed families falsifies H1 on the tested models and substrate. Wide intervals are inconclusive, not invariance.

Evidence expectation: a trajectory-by-transformation paired heatmap plus a table of mean/quantile |score delta|, directional shifts, decision-flip rate, false-accept/false-reject changes, and task-clustered uncertainty. The table must distinguish parser/tokenization effects, context overflow, and invalid renderings from substantive verifier sensitivity.

Closest current collision: logic-grounded metamorphic testing already establishes invariant-pair testing for LLM reasoning, while trajectory-judge (2609.00038) uses controlled agent-trajectory faults. Neither inspected work establishes paired representation invariance of outcome verifiers; this absence remains provisional pending full survey.
