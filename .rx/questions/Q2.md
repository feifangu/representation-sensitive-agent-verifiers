# Which transformation contract makes representation invariance identifiable rather than an arbitrary robustness test?

Supporting measurement question. Define an immutable typed event graph as the semantic object and render it through transformations assigned to tiers: Tier A mechanically bijective renderings; Tier B mechanically outcome-preserving but potentially evidence-salience-changing transforms; Tier C externally validated semantic edits. The primary claim should rely on Tier A. Tier B/C are stress tests and cannot inherit the same causal interpretation without validation.

Four-axis novelty delta: framing = validity of the intervention is a first-class estimand; mechanism = round-trip parser equality, canonical event hashes, preserved grader result, and explicit evidence-coverage checks; insight = separate representation sensitivity from information deletion, evidence fabrication, and changed process correctness; domain = terminal-agent traces. This is a constructive benchmark contribution, not merely a taxonomy.

Prediction/falsifier: Tier A transformations should have near-perfect round-trip validity; if common trajectory substrates cannot support enough bijective transformations or verifier inputs cannot be made semantically equivalent, the central causal claim is not testable there and the project must narrow or stop. Human/external semantic validation alone does not upgrade Tier C to mechanical equivalence.

Evidence expectation: a transformation ledger reporting invertibility, event/hash equality, token/length change, grader replay result where possible, critical-evidence coverage, invalid-pair rate, and examples of rejected transformations. A negative audit that eliminates proposed chatter/reordering families is a valid result.
